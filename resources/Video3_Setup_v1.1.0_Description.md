TheTowerAnalyzer just got dramatically easier to set up. In version 1.1.0 you can submit
battle reports straight from your phone — no Google Cloud, no Drive folders, no make.com,
no Tasker. Install the desktop app, install the Android app (or import the iOS Shortcut),
paste in your Player ID, and you're done. This video walks you through the whole thing
start to finish.

📺 First time here? Watch the showcase video first: https://youtu.be/AwEHBKZiA5s
📄 Written setup guide (centralized mode): https://github.com/draukadin/TheTowerAnlyzer/blob/master/resources/Centralized_Setup_Guide.md

WHAT'S NEW IN 1.1.0:
✅ Centralized submission — send reports from your phone, the desktop app picks them up automatically
✅ Native Android app (Google Play) and iOS Shortcut — no Tasker, no webhooks
✅ All run types supported: Farming, Tournament, Milestone, Event, and Dissonance (all sub-types)
✅ Pick your closest AWS region (US East, EU West, AP Northeast) for best speed
✅ Cloud backup & restore — back up your local database to the cloud and restore it on any machine
✅ Legacy Google Drive / make.com / Tasker setups still work unchanged

WHAT YOU'LL NEED:
1 — A Windows PC or Mac to run the desktop app
2 — Your Player ID from The Tower (Settings → copy the ID under your username)
3 — An Android phone (Play Store) OR an iPhone on iOS 16+ with the Shortcuts app
4 — The Tower installed on that same device
